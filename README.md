# pane's website

The landing page for [pane](https://github.com/lemonadesaltbagel/pane), Windows-style window management for the Mac,
served by GitHub Pages at https://lemonadesaltbagel.github.io.

One static page (`index.html`) with no build step. The window images in `assets/windows` are screenshots of macOS, and
the app icons in `assets/icons` are Apple's; both are shown only to illustrate pane running on a Mac. Mac and macOS
are trademarks of Apple Inc. Windows is a trademark of Microsoft Corporation. pane isn't affiliated with either.
